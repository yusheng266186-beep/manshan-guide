# 慢山行 · 丽江×香格里拉 6天5晚双人慢度假手册

把整个文件夹（index.html、css/、js/、assets/）保存在手机上，用浏览器打开 index.html 即可离线使用。

## 使用小贴士
- 首次打开需联网加载字体；之后浏览器会缓存，弱网也能正常阅读（字体缺失时自动回退系统宋体/黑体）。
- 顶部导航右侧有「搜索」：输入关键词（如 腊排骨 / 转经筒 / 停损线）可直接跳转到对应位置，还会自动展开折叠内容、切换标签页并高亮闪烁提示。
- 「清单」区的勾选会自动保存在本机浏览器，旅途中可随时打勾。
- 8 月 6 日—11 日期间打开，行程总览会自动标出「今日」所在的卡片。
- 所有时间轴节点点击可展开：详细安排 / 内容或餐饮 / 交通 / 备注。
- 全部配图均为高清原图（未压缩），建议 Wi-Fi 下首次打开缓存。

文件夹内无其他依赖，可直接通过微信「文件」发送、或放到网盘/AirDrop 传输。
