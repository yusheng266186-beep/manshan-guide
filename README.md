## 行程定位

- 出发地：成都；
- 目的地：丽江、香格里拉；
- 旅行类型：双人慢度假；
- 住宿安排：丽江古城花间府·植梦连续入住5晚；
- 行程日期：2026.08.06—08.11；
- 设计原则：以丽江为主场、以香格里拉为重点体验，每天只安排一个主场景。

手册把“旅行中可能需要查”的信息放在一起，包括每日时间轴、文化预习、摄影指南、美食清单、备用路线、预约、交通、安全和出发清单。

## 主要内容

### 六日总览

- 每天的日期、城市和主要主题；
- 每日交通、住宿和节奏；
- 当天主场景与雨天、身体状态备用方案；
- 自动标记当前日期卡片，方便旅行期间定位。

### 每日详细时间轴

点击时间轴节点可以展开：

- 详细安排；
- 内容或餐饮；
- 交通方式；
- 备注；
- 需要提前确认的事项。

时间轴的目标是帮助两个人保持从容，而不是强迫每天完成所有景点。

### 搜索功能

顶部导航提供搜索入口。可以搜索：

- 腊排骨；
- 转经筒；
- 黑龙潭；
- 玉湖村；
- 停损线；
- 预算；
- 穿搭；
- 酥油茶；
- 其他手册正文关键词。

搜索结果会定位到相应内容，并在必要时展开折叠区域或切换标签。

### 文化预习

通过文字和卡片了解：

- 丽江古城与纳西文化；
- 香格里拉的高原环境和地方文化；
- 沿线建筑、信仰、饮食和生活方式；
- 到达现场后值得观察的细节。

### 摄影指南

每个地点提供氛围和拍摄建议，包括：

- 光线和时间；
- 建筑、街巷、山景和院落；
- 双人合照；
- 雨天和室内替代拍法；
- 不打扰当地居民和其他游客的拍摄方式。

### 美食清单

- 云南地方菜和小吃；
- 腊排骨、酥油茶等旅行主题食物；
- 点餐、口味和分量建议；
- 餐厅和店铺搜索线索；
- 适合两人慢慢吃的安排。

店铺营业、价格和评价可能变化，页面中的推荐只作为出发前筛选线索。

### 备选与停损线

手册专门为雨季、高原和临时变化准备了备用逻辑：

- 原景点无法执行时只替换一个方案；
- 不因为取消一个景点而叠加多个新景点；
- 出现持续头痛、恶心、胸闷、明显乏力或交通预警时，优先休息；
- 以两人的身体状态和安全为最终判断标准。

### 清单

清单区可以勾选：

- 证件；
- 预约和车票；
- 衣物；
- 防晒；
- 药品；
- 摄影设备；
- 旅行日常用品；
- 出发前确认事项。

勾选状态保存在当前浏览器本地，适合旅行过程中持续使用。

## 使用方式

### 在线使用

打开 Pages 地址：

    https://yusheng266186-beep.github.io/manshan-guide/

首次使用建议在网络较好的环境打开一次，让字体和高清图片完成加载。

### 手机离线使用

项目目录可以整体保存到手机：

    manshan-guide/
    ├── index.html
    ├── css/
    ├── js/
    └── assets/

然后用手机浏览器打开 index.html。也可以把整个文件夹通过微信文件、网盘、AirDrop 或数据线传到手机。

### 本地预览

在项目根目录启动：

    python -m http.server 8080

访问：

    http://localhost:8080/

使用静态服务器时，字体、图片、样式和脚本的相对路径更稳定。

## 目录结构

    manshan-guide/
    ├── index.html    # 页面结构、行程内容和入口
    ├── css/          # 旅行手册样式和响应式布局
    ├── js/           # 行程、搜索、清单和页面交互
    ├── assets/       # 高清图片、图标和视觉素材
    └── README.md     # 项目说明

## 技术实现

- 原生 HTML、CSS 和 JavaScript；
- 响应式移动端布局；
- CSS 变量和自定义缓动动画；
- 搜索覆盖层和内容定位；
- 时间轴、折叠卡片和标签页；
- localStorage 保存清单勾选；
- GitHub Pages 静态托管；
- 不依赖后端数据库和构建工具。

页面的高清图片未压缩，首次加载可能较慢。建议在 Wi-Fi 下预加载，旅行途中再使用缓存或本地副本。

## 修改手册

- 行程和正文主要在 index.html；
- 样式和动画在 css/；
- 搜索数据、清单或交互逻辑在 js/；
- 图片和图标在 assets/；
- 修改章节标题时，同步检查顶部导航和搜索索引；
- 修改日期时，同步检查首页日期、行程卡片和“今日”判断逻辑；
- 更换图片后检查移动端加载速度和图片授权；
- 发布前在手机上测试搜索、折叠、清单和返回顶部。

## 出行安全与信息时效

天气、交通、酒店、景区、餐厅、门票和预约信息会发生变化。出发前请重新确认：

- 12306 车次和改签规则；
- 酒店入住、早餐和服务；
- 香格里拉天气与道路状况；
- 景区开放和预约；
- 餐厅营业与价格；
- 个人身体状态和药品准备。

高原旅行中，若出现明显不适，不要硬撑行程，应及时休息并根据情况寻求医疗帮助。
